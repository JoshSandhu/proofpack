## 1. What landed

New package `src/proofpack/stats/` (numpy-only import path; scipy imported lazily inside the one
function that needs it), plus the output schema and the F14 fixture.

**`stats/number.py` — the `Number` object (D1 §4.1)**
- Fields: `est, ci_lo, ci_hi, ci_level, method, n, k, n_pos, n_neg, n_cases, flags, suppressed,
  not_estimable_reason`. `as_dict()` drops the denominator keys that do not apply.
- **The invariant is enforced in `__post_init__`, not by convention**: a `Number` must carry both
  interval bounds, *or* be `suppressed`, *or* name a `not_estimable_reason` from a closed enum.
  Constructing one with neither raises `ValueError`. Also rejected: a half-open interval, an
  interval whose `method` is `none`, an interval that also carries a reason, an unknown method,
  an unknown reason, an unknown flag, `ci_lo > ci_hi`.
- `METHODS` (D1 §4.1 enum + two additions, below), `NOT_ESTIMABLE_REASONS` (11 typed reasons),
  `FLAGS` (7, incl. the R2 §3.3 precision tiers, applied by `with_precision_flags()`).

**`stats/proportions.py`**
- `wilson_bounds` (default, no continuity correction) and the continuity-corrected form
  (available, never default, flagged `continuity_corrected`).
- `clopper_pearson_bounds`: **closed form at 0/n and n/n** — `(0, 1−(α/2)^(1/n))` and its mirror —
  so the exactly-the-cases-D1-asks-for boundary path needs no scipy at all; `scipy.stats.beta.ppf`
  for 0<k<n, returning `None` (→ `scipy_unavailable` reason) when scipy is absent.
  `proportion_exact_alternative()` returns a Clopper–Pearson `Number` **only** at 0/n and n/n,
  flagged `shown_alongside_wilson_at_boundary`; elsewhere `None` (it is an oracle, not output).
- `wald_bounds`: test-only. `"wald"` is not in the method enum, and a test greps `src/proofpack`
  to prove the string never appears there, so a Wald interval cannot be rendered.
- `newcombe10_bounds` / `newcombe11_bounds` (unpaired, square-and-add of plain / continuity-
  corrected Wilson intervals); `newcombe_paired_bounds` + `_paired_phi` (paired method 10, with
  the numerator of φ̂ continuity-corrected to `max(eh−fg−n/2, 0)` when `eh > fg`).
  `difference_unpaired()` / `difference_paired()` wrap them as `Number`s.
- `Table2x2` and `two_by_two_metrics()`: Se/Sp (or PPA/NPA), PPV, NPV, accuracy, prevalence
  (Wilson); Youden J and balanced accuracy (**Newcombe-10** — J = Se − FPR is a difference of two
  *independent* proportions, so this is the right interval, not a made-up one); LR+, LR−, DOR
  (log-scale delta, `log_delta`); F1 and MCC (see §2 — typed reason, no interval).
- PPA/NPA routing via `reference_standard_type="comparator"`: same numbers, different metric ids;
  a test serialises the whole block and asserts the strings "sensitivity"/"specificity" are absent.
- `ppv_at_prevalence` / `npv_at_prevalence`: Bayes point estimate, **logit-scale delta interval**.
  Derivation is in the docstring: `logit PPV = logit(π) + log Se − log(1−Sp)`, so
  `Var = (1−Se)/(Se·n1) + Sp/((1−Sp)·n0)` (the log-LR+ variance), back-transformed with the
  logistic. Mercaldo 2007 is cited **[unverified]** — the paper was not fetched; the form used is
  derived from first principles and tested by the identity PPV(study prevalence) = TP/(TP+FP).
- `indeterminate_both_ways()`: as-positive and as-negative tables from a determinate 2×2 plus the
  reference-standard split of the indeterminates. Both are returned; neither is a default.
- `table_2x2_from_arrays()`: counts from aligned `y_true` / boolean-prediction arrays.

**`schema/output_schema_v1.json`** (new, JSON Schema 2020-12; packaged into the wheel, added to

## 2. What was cut, and what is honestly unverified

**Cut — nothing from the brief.** All of E2 landed.

**F14 provenance — read this.** The brief said "fetch the Newcombe 1998 PDF if reachable; if not,
use the widely reproduced values and mark the source honestly". It was **not** reachable: the
build environment's egress allowlist returns `403 Host not in allowlist: www.stats.org.uk`, and
the agent fetch path additionally fails TLS hostname verification for that host. The Wiley copy is
paywalled. So `fixtures/newcombe_table2.json` records `transcribed_from_primary_pdf: false`,
`status: "[unverified against the primary PDF]"`, the exact URL attempted and why it failed, and
the actual secondary source (WUSS 2016 paper 127, which states it recasts Newcombe's Table II).
A test asserts the fixture keeps saying so, so nobody can quietly upgrade the claim.
The paired examples come from an automated read of a university-hosted copy of the paired paper
and are marked the same way.
**Corroboration (not proof):** `newcombe10_bounds`, `newcombe11_bounds` and `newcombe_paired_bounds`
were written from the published formulae, not from these numbers, and reproduce all nine intervals
to 4 dp on the first run — including a boundary (9/10 vs 3/10) and a double boundary (10/10 vs
0/20), where a mis-transcription would be very unlikely to agree. Treat that as strong but not
conclusive; a human should still open the paper (see §5).

**F1 and MCC have no interval.** There is no standard closed-form CI for either. Rather than
invent one or silently omit them, they are emitted with `est`, `not_estimable_reason:
"analytic_ci_unavailable"` and the flag `ci_pending_bootstrap`. Day 4's `stats.bootstrap` should
fill them. The renderer must not print an estimate whose Number has no CI (D1 §4.1) — so today
F1/MCC are computed but not renderable, which is the intended conservative state.

**Two additions to the D1 §4.1 `method` enum**, both in the schema and the code enum:
`logit_delta` (D1's prose asks for a "logit-scale interval" for PPV/NPV at prevalence but the enum
only had `log_delta`) and `newcombe11` (the brief asks for methods 10 *and* 11). Flagged here so
the change is a decision, not a drift.

**Not built today** (correctly out of scope): cluster-aware proportions (day 4 bootstrap), the
subgroup difference machinery (day 6), wiring these functions into `ingest()` to emit a document
(day 4 assembles `overall`), F5 McNemar (day 8).

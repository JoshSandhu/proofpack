## 3. "No Number without a CI" — attempted to break it

Eleven constructor attacks, **zero smuggled through**:

| attack | outcome |
|---|---|
| est only, no CI, no reason, not suppressed | `ValueError: Number has no confidence interval and no not_estimable_reason` |
| same with `method="none"` | rejected |
| half-open interval (`ci_lo` only / `ci_hi` only) | rejected, both directions |
| interval with `method="none"` | `a Number with an interval must name the method that made it` |
| interval **and** a not-estimable reason | rejected |
| free-text reason `"because I said so"` | `unknown not_estimable_reason` |
| empty-string reason | rejected |
| unknown method `"wald"` with a valid interval | `unknown method 'wald'` |
| inverted interval `ci_lo > ci_hi` | rejected |
| unknown flag | `unknown flag 'looks_fine'` |

Schema layer, probed separately with well-formed documents: a no-CI/no-reason Number, a bogus
reason, a half-open interval, an interval carrying a reason, and `method: "wald"` are all
**rejected** by `schema/output_schema_v1.json`; a no-CI Number with a valid enum reason and a
well-formed Wilson interval are accepted. The invariant genuinely holds in two independent layers.

**Hardening item 1 (not a blocker).** `Number` is a *mutable* dataclass, so the invariant is
construction-time only. `n = Number(est=.5, ci_lo=.2, ci_hi=.8, method="wilson"); n.ci_lo = None;
n.ci_hi = None` produces an in-memory Number with an estimate and no interval, and `as_dict()`
serialises it without complaint. The schema catches it at document-validation time (I confirmed
that exact mutated shape is rejected), so nothing can reach a customer document through this path
*provided the document is always schema-validated*. Recommendation: `@dataclass(frozen=True)`, or
re-run `__post_init__`'s checks inside `as_dict()`, so the guarantee does not depend on a
downstream validation step.

**Note.** A not-estimable Number keeps its `est` in `as_dict()` (by design — F1/MCC carry an
estimate awaiting day-4 bootstrap). The "never render a bare estimate" rule therefore still has to
be honoured by the renderer, which does not exist yet. Day 5 must carry a test for it.

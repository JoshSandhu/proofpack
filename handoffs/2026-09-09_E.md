## 1. What landed

**`src/proofpack/stats/discrimination.py`** — numpy + stdlib only, no scipy anywhere
(normal quantile from `statistics.NormalDist`, normal tail from `math.erfc`).

- `auroc_mann_whitney(scores, positives)` — AUROC by the Mann–Whitney statistic with
  **midranks** for ties. This is the day-1 H01 function, *moved* here; `gates.py` now
  re-exports it (`gates.auroc_mann_whitney` is unchanged for callers, so all 51 day-1 tests
  still pass unmodified). Aliased as `auroc`.
- `delong_covariance(score_matrix, positives)` — DeLong 1988 structural components via the
  **Sun & Xu 2014** O(N log N) midrank formulation, written from the algorithm (nothing
  vendored, so R2 §10's licence question never arises). Handles k classifiers at once and
  returns `(aucs, S)` where `S` is the full k×k covariance matrix. `delong_variance()` is
  the single-classifier wrapper.
- `wald_ci` and `logit_ci`. `auroc_number()` picks the **logit** interval as primary when
  `AUC > 0.9` or either class has < 30 cases (D1 §3.1), Wald otherwise, and always returns
  the other as `auroc_secondary`. A Wald interval that leaves [0,1] is clamped for rendering
  **and** flagged `wald_interval_exceeds_unit_range` so the clamp is visible, never silent.
- `paired_delong(a, b, positives)` — two correlated ROC curves on the same cases:
  `Var(A−B) = S_aa + S_bb − 2 S_ab`, a z statistic, a two-sided p-value, and a difference
  `Number` with a Wald interval on that variance.
- `roc_curve()` — `[[fpr, tpr, threshold], …]` from `(0,0,+inf)` to `(1,1,·)`, one point per
  distinct score. `locate_operating_points()` marks each declared operating point on it
  using the declared rule (`>=`, `>`, `<=`, `<`), not an assumed one.
- `DiscriminationResult` / `PairedDeLong` dataclasses matching `$defs.thresholdFree` in
  `output_schema_v1.json` (written yesterday; filled, not redesigned).

**Typed refusals, no silent fallbacks** — every one of these is a `Number` with no interval
and an explicit reason from the day-2 enum:
| situation | reason |
|---|---|
| clustered rows (`clustering.unit = case_id`, or rows > cases) | `clustered_data_analytic_ci_invalid` |
| AUC exactly 0 or 1, or SE 0 | `boundary_estimate` |
| no positives or no negatives | `single_class` |
| fewer than 2 in a class | `insufficient_positives` / `insufficient_negatives` |
The clustered case keeps the (correct) point estimate and `n_cases`, and is flagged
`ci_pending_bootstrap` for day 4.

## 6. Open questions (≤5)

1. **Logit-vs-Wald primary rule.** D1 says logit when `AUC > 0.9` **or** class < 30. That
   means most subgroup tables will show logit and the overall table Wald — inconsistent
   within one document. Should the whole document use one rule (I'd argue: logit everywhere,
   Wald as the footnote) rather than switching per row?
2. **Clamping.** The secondary Wald interval is clamped to [0,1] and flagged. Alternative:
   print `1.1036` unclamped so the reader sees why it is not primary. Which does an FDA
   reviewer prefer?
3. **Small-class DeLong.** Today 5/5 gets a DeLong interval plus `very_low_precision`.
   After day 4, should DeLong be *refused* below 10 per class (R2 §1.3 reads that way) or
   shown alongside the bootstrap?
4. **Tie handling in `roc_curve`.** One point per distinct score, no intermediate-point
   dropping (unlike sklearn's default). Good for a rendered plot; it makes the array longer
   for large n. Cap the emitted array (e.g. 2000 points, thinning only collinear ones) before
   this reaches the JSON document?
5. **Paired DeLong difference interval.** Wald on `Var(A−B)`, which can cross ±1 at tiny n.
   A logit-type transform for a *difference* is not standard. Leave as Wald, or bootstrap it
   on day 4 for consistency?
